获取代理（/api/fetch）：支持 Header 或 Query 两种认证方式
curl -H "Authorization: Bearer <api_key>" https://proxy.mui.moe/api/fetch
curl "https://proxy.mui.moe/api/fetch?api_key=<key>"

请求转发（/api/relay）：仅支持 Query 方式认证，Header 和 Cookie 会原样转发给目标
curl "https://proxy.mui.moe/api/relay?api_key=<key>&url=https://httpbin.org/ip&country=US"
默认总超时 600 秒，可在 config.toml 的 relay.timeout_secs 调整
